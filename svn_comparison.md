# Сравнение Git и SVN

## 1. Почему в Git ветвление "дешёвое", а в SVN - "дорогое"?

В Git ветка - это указатель на коммит, создаётся локально и быстро. В SVN ветка обычно создаётся как копия каталога в репозитории, например `/trunk -> /branches/feature`, поэтому требует серверной операции и воспринимается как отдельная копия проекта.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет. `svn commit` создаёт ревизию на центральном сервере, поэтому нужно соединение с сервером. Локально можно только сохранить изменения или патч, например:

```bash
svn diff > changes.patch
```

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

Когда нужны строгий централизованный контроль, права доступа на каталоги, частичная выгрузка проекта, блокировки бинарных файлов или поддержка легаси-инфраструктуры. Пример: хранение игровых ассетов с блокировкой файлов перед редактированием.
